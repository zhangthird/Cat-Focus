# 🐱 Cat Focus - 猫咪专注计时器

一个可爱的番茄钟专注计时器，帮助你保持专注，提升工作效率！通过专注获得鱼干奖励，陪伴你的猫咪一起成长。

## ✨ 特性

- 🎯 **专注计时**: 默认中文、25 分钟专注，可设置 1–999 分钟，支持暂停与继续
- 🐟 **鱼干奖励系统**: 完成专注任务获得鱼干奖励，激励持续专注
- 📊 **数据统计**: 
  - 总专注时长统计
  - 当前鱼干余额
  - 近7天专注趋势图表
- 🎨 **精美界面**: 采用现代化设计，界面简洁美观
- 💾 **本地存储**: 数据保存在本地，隐私安全
- 📱 **响应式设计**: 支持各种设备尺寸

## 🚀 使用方法

### 在线使用

[打开猫咪番茄时钟（Sites）](https://cat-focus-zhird.icuicheng.chatgpt.site)。当前站点仅所有者可访问，访问权限以 Sites 设置为准。

### 本地使用

下载并用浏览器打开 `cat-focus.html`，无需安装或构建。文件包含打包后的 React、应用逻辑和样式；在线字体不可用时会使用系统字体。

进度、设置与收藏保存在当前浏览器的本地存储中，不会自动跨设备或在网站与本地文件之间同步。可通过“设置 → 本机数据与备份”导出 JSON，再在另一处导入。正在进行的计时不会在刷新或关闭页面后恢复。

### 功能说明

1. **开始专注**
   - 点击"开始"按钮启动专注计时器
   - 设置你想要专注的时间（分钟）
   - 计时器开始倒计时

2. **获得奖励**
   - 完成专注任务后自动获得鱼干奖励
   - 鱼干可在商店中购买猫咪和椅子，并在图鉴中查看收藏

3. **查看统计**
   - 查看总专注时长
   - 查看当前鱼干余额
   - 查看近7天的专注趋势图表

## 🛠️ 技术栈

- **React 19.2.0**: 前端框架
- **React DOM**: DOM 渲染
- **Vite**: 原始应用的打包工具；此仓库保留单文件成品，无需运行构建命令
- **本地存储**: 数据持久化

## 💡 提示

- 建议每次专注时间设置在 25-50 分钟之间
- 专注期间避免查看手机和其他干扰
- 完成专注后适当休息，保持良好的工作节奏
- 定期查看统计数据，了解自己的专注习惯

## 本次 Sites 版本同步

`cat-focus.html` 与 2026-09-13 发布的 Sites 页面内容一致，包含以下调整：

- 修复暂停后剩余时间被重置的问题；倒计时按实际经过时间更新。
- 完成弹窗显示本次实际获得的鱼干奖励。
- 按本地日期记录专注统计，避免 UTC 日期偏移。
- 校验导入数据与自定义时长，防止无效存档破坏页面。
- 将未配置 API 的猫猫教练改为本地固定规则提示，不调用大模型。
- 添加网站图标、中文元信息和部分键盘操作支持。

这是专注倒计时，完成后提示手动休息，不会自动启动休息计时。Sites 托管身份配置不属于应用文件，因此未同步到此仓库。
